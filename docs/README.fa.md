## دانلود
**[آخرین نسخه →](https://github.com/Nethyric/orca/releases/latest)** — فایل زیپ را باز کنید و `ORCA.exe` را اجرا کنید. بدون نصب، بدون حساب کاربری، بدون کلید API.
ORCA هنگام اجرا نسخه‌های جدید را از GitHub بررسی می‌کند و به‌روزرسانی یک‌کلیکی پیشنهاد می‌دهد (تنظیمات ← به‌روزرسانی).

## مدل‌های رایگان چطور کار می‌کنند؟ (هیچ کلیدی داخل برنامه نیست)
برنامه **هیچ کلید API** ندارد. مدل‌های داخلی از طریق **ابر ORCA** ارائه می‌شوند — یک [Cloudflare Worker](../gateway/) کوچک که کلیدهای واقعی را به‌صورت Secret رمزشده نگه می‌دارد،
بین چند کلید می‌چرخد، کلیدهای مرده را خودکار غیرفعال می‌کند و در صورت محدودیت نرخ، خودکار به کلید بعدی می‌رود.
شارژ سهمیه یا تعویض ارائه‌دهنده = تغییر یک Secret؛ نه نسخهٔ جدیدی لازم است، نه کاربر چیزی می‌فهمد.
می‌توانید ارائه‌دهنده‌های خودتان (OpenRouter یا هر endpoint سازگار با OpenAI) را هم در تنظیمات اضافه کنید؛ آن کلیدها فقط روی دستگاه خودتان می‌مانند.

## زبان‌ها و فونت
زبان پیش‌فرض انگلیسی است؛ برنامه سیستم‌های فارسی، روسی و چینی را خودکار تشخیص می‌دهد. هر زبان فونت مخصوص خودش را دارد:
Inter (لاتین/سیریلیک)، وزیرمتن (فارسی، چیدمان راست‌به‌چپ)، Noto Sans SC (چینی ساده‌شده). OCR هم انگلیسی + زبان رابط را می‌خواند.

## چه کارهایی می‌کند
- **ایجنت واقعی**: فایل می‌سازد/ویرایش می‌کند، دستور اجرا می‌کند، وب را می‌گردد و می‌خواند، برنامه‌ریزی می‌کند، خودش را اصلاح می‌کند، زیرایجنت‌های موازی، حافظه، چک‌پوینت و برگشت.
- **چندمدلی با جایگزینی خودکار**: MiniMax M2.7، DeepSeek V4 Flash، GLM 5.3 — اگر یکی از دسترس خارج شد، بعدی ادامه می‌دهد.
- **رسانه**: OCR تصویر، دانلود اینستاگرام/تیک‌تاک/X/یوتیوب، ترندها، تولید تصویر و ویدیو، ویرایش ویدیو با ffmpeg.
- **آفیس**: Word/Excel/PowerPoint می‌سازد و می‌خواند.
- **مقایسه و نبرد مدل‌ها**، حالت Plan، منوی اسلش، میان‌برها، تم روشن/تیره.

## اجرا از سورس
```bash
npm i
npm run fetch-bins   # ffmpeg.exe, yt-dlp.exe, tessdata
npm start            # دسکتاپ (Electron)
npm run web          # حالت وب → http://localhost:7860
npm run dist:win     # زیپ پرتابل ویندوز → release/
```

## راه‌اندازی برای نگه‌دارندگان (GitHub + Cloudflare)
راهنمای قدم‌به‌قدم انگلیسی: [SETUP.md](SETUP.md). خلاصه:
1. مخزن `Nethyric/orca` را بسازید و سورس را push کنید.
2. در Cloudflare حساب رایگان بسازید؛ Account ID و یک API Token (قالب «Edit Cloudflare Workers») بگیرید.
3. در GitHub ← Settings ← Secrets این ۵ مورد را اضافه کنید: `CLOUDFLARE_API_TOKEN`، `CLOUDFLARE_ACCOUNT_ID`، `UPSTREAMS` (JSON کلیدها)، `BUILD_TOKEN`، `ADMIN_TOKEN`.
4. Actions ← «Deploy gateway» را اجرا کنید.
5. `git tag v1.5.0 && git push --tags` ← Action «Release» زیپ ویندوز را می‌سازد و منتشر می‌کند.

کلید تمام شد؟ Secret مربوط به `UPSTREAMS` را ویرایش کنید و workflow را دوباره اجرا کنید — تمام.
