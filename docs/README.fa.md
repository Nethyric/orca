<h1 align="center">ORCA</h1>
<p align="center">ایجنت هوش مصنوعی خودمختار و متن‌باز برای دسکتاپ — با هر مدلی، یا بدون هیچ مدلی.</p>
<p align="center"><a href="../README.md">English</a> · فارسی</p>

---

ORCA یک ایجنت دسکتاپ است: کار را توضیح می‌دهید، برنامه می‌ریزد، کد می‌نویسد، اجرا می‌کند، خطاها را می‌خواند و درست می‌کند — روی کامپیوتر خودتان و داخل پوشهٔ کاری‌ای که انتخاب کرده‌اید. مدل‌های داخلی بدون هیچ تنظیمی کار می‌کنند و می‌توانید بیش از ۲۰۰ ارائه‌دهنده یا هر آدرس سازگار با OpenAI را با کلید خودتان اضافه کنید.

- **خودمختار**: ۴۱ ابزار واقعی — شل، Node/Python، ویرایش فایل، جست‌وجوی وب، HTTP، بررسی صفحه در مرورگر بدون سر، اسناد آفیس، رسانه، OCR، تولید تصویر و ویدیو، زیرایجنت‌ها.
- **هر مدلی**: مدل‌های داخلی با جایگزینی خودکار، به‌علاوهٔ ارائه‌دهنده‌های خودتان (ابری یا محلی). کلیدها هیچ‌وقت از دستگاه شما خارج نمی‌شوند.
- **سه حالت گفتگو**: مستقیم، مقایسهٔ دو مدل، و نبرد ناشناس با جدول امتیاز محلی.
- **نقطهٔ بازگشت و دیف**: هر تغییر فایل ذخیره می‌شود؛ با یک کلیک برمی‌گردد.
- **چهار زبان**: English، Русский، 中文، فارسی — با فونت مناسب هر زبان.
- **خصوصی**: بدون حساب کاربری، بدون تله‌متری.

## نصب

**ویندوز (پرتابل)** — آخرین زیپ را از [Releases](https://github.com/Nethyric/orca/releases/latest) بگیرید، باز کنید و `ORCA.exe` را اجرا کنید. بدون نصب، بدون دسترسی مدیر.

**از سورس** (ویندوز، مک، لینوکس):

<div dir="ltr">

```bash
git clone https://github.com/Nethyric/orca.git
cd orca
npm install
npm start          # برنامهٔ دسکتاپ
npm run web        # یا رابط وب در http://localhost:7860
```

</div>

> نسخهٔ سورس کلید صندوق (vault) ندارد؛ بنابراین مدل‌های داخلی فقط در نسخه‌های منتشرشده فعال‌اند. در نسخهٔ سورس یک ارائه‌دهندهٔ خودتان را در **تنظیمات ← مدل‌ها** اضافه کنید.

## افزودن ارائه‌دهنده

**تنظیمات ← مدل‌ها ← افزودن ارائه‌دهنده**: یکی را از فهرست انتخاب کنید (یا «سفارشی» برای هر آدرس سازگار با OpenAI)، کلید را بچسبانید، **کشف خودکار** را بزنید تا مدل‌ها فهرست شوند، **تست**، **ذخیره**. راهنمای کامل: [providers.md](providers.md).
