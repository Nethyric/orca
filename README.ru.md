ORCA — настольный агент, который планирует, пишет код, запускает его, читает ошибки и исправляет их: на вашей машине, в ваших файлах. Встроенные модели работают сразу после установки; при желании подключаются 200+ провайдеров или любой OpenAI-совместимый эндпоинт с вашим ключом.

- **Автономность по умолчанию.** 46 настоящих инструментов: оболочка, Node/Python, редактирование файлов, веб-поиск, HTTP, headless-браузер, документы Office, медиа, OCR, генерация изображений и видео, фоновые процессы, суб-агенты. Запросы на создание проектов сначала реализуются с разумными значениями по умолчанию — вопрос задаётся только тогда, когда работа действительно заблокирована (например, нужен токен бота), и только после того, как код уже существует.
- **Любая модель.** Встроенные модели с автоматическим переключением при сбоях плюс ваши собственные провайдеры (облачные или локальные). Ключи никогда не покидают ваше устройство.
- **Создаёт сайты целиком.** Модель пишет содержимое — тексты, позиции, цены, FAQ, отзывы — а `scaffold_site` за один шаг превращает его в готовый современный многостраничный сайт (дизайн-токены, тёмная/светлая тема, hero-блок, карточки, статистика, каталог с фильтрами и корзиной, формы с валидацией, RTL при необходимости), после чего каждая страница проверяется в headless-браузере. Без заглушек и недостроенных страниц.
- **Запускает то, что построил.** Боты, dev-серверы и воркеры стартуют как фоновые процессы, живут между ходами и имеют живой лог, определённые порты и кнопку «Стоп» в панели процессов. Генерация изображений и видео подключается к любому провайдеру Images API / Videos API (OpenAI, Routeway, Together, xAI, Sora, Replicate, fal.ai) с кнопкой проверки в настройках.
- **Знает, что умеет.** На вопрос «что ты умеешь?» ответ генерируется по живой проверке возможностей вашей установки — подключённые модели, имеющиеся бинарники, включённые движки — а не по заготовленному списку.
- **Движок решений (опционально).** Подключите модель System One — и ORCA получает калиброванные суждения за ~0,2 с: более умная маршрутизация, семантическая оценка риска команд, проверка каждого ответа (нечитаемый, обещанное-но-несделанное, неверный язык), переранжирование результатов поиска.
- **Три режима диалога.** Прямой, параллельное сравнение или «слепая битва» с локальной таблицей лидеров.
- **Контрольные точки и диффы.** Каждое изменение файлов фиксируется в снапшоте; любой шаг восстанавливается одним кликом.
- **Создан для долгой работы.** Обрывы вывода продолжаются прозрачно, длинные вставки превращаются в файлы, остановленные ответы можно продолжить, а закрепления, заметки и ветки удерживают длинные диалоги в русле.
- **Четыре языка.** English, Русский, 中文, فارسی — с соответствующей типографикой.
- **Приватность.** Без аккаунтов и телеметрии. Всё хранится в локальной папке данных, которой управляете вы.

## Установка

Скачайте сборку для своей системы из [релизов](https://github.com/Nethyric/orca/releases/latest):

| Платформа | Файл | Запуск |
|---|---|---|
| Windows 10/11 x64 | `ORCA-Setup-<version>-win-x64.exe` (установщик) или `ORCA-<version>-win-x64-portable.exe` | запустите; SmartScreen → *Дополнительно* → *Выполнить всё равно* |
| macOS 12+ (Apple Silicon) | `ORCA-Agent-<version>-mac-arm64.dmg` / `.zip` | перетащите в Applications; первый запуск: правый клик → Открыть |
| macOS 12+ (Intel) | `ORCA-Agent-<version>-mac-x64.dmg` / `.zip` | то же самое |
| Linux x64 | `ORCA-Agent-<version>-linux-x64.AppImage` / `.tar.gz` / `.deb` | `chmod +x` и запустите, или `sudo apt install ./ORCA-Agent-*.deb` |

Сборки не подписаны кодом; к каждому релизу прилагается `SHA256SUMS`. Приложение обновляет себя само: проверяет канал релизов, фоново скачивает пакет для вашей ОС/процессора (с докачкой, с зеркалами при блокировке GitHub), проверяет SHA-256 и устанавливает обновление при перезапуске — браузер не нужен (Настройки → Обновления).

**Из исходников** (Windows, macOS, Linux):

```bash
git clone https://github.com/Nethyric/orca.git
cd orca
npm install
npm start          # настольное приложение
npm run web        # или: веб-интерфейс на http://localhost:7860
```

> [!TIP]
> В релизных сборках встроенные модели работают сразу. В копии из исходников ключа хранилища нет — добавьте провайдера в **Настройки → Модели** (или задайте `ORCA_VAULT_KEY`, если вы сопровождающий). См. [docs/setup.md](docs/setup.md).

## MCP (Model Context Protocol)

В ORCA встроен минималистичный MCP-клиент без зависимостей: подключайте внешние серверы инструментов в Настройки → MCP (или вставьте конфигурацию `mcpServers` из Claude Desktop как есть). Поддерживаются оба транспорта — `stdio` (локальный подпроцесс) и Streamable HTTP (с обратной совместимостью с устаревшим SSE). Серверы запускаются лениво и тихо переподключаются; каждый результат считается недоверенным содержимым, манифесты инструментов фингерпринтятся для обнаружения незаметной подмены, а каждый инструмент можно включать и выключать отдельно. Режим `compact` держит схемы сервера вне контекста, пока агент не запросит их сам.

## Провайдеры

Откройте **Настройки → Модели → Добавить провайдера**, выберите провайдера из каталога (или *Custom* для любого OpenAI-совместимого URL), вставьте ключ, нажмите **Discover** для списка моделей, **Test**, **Save**. Ключи хранятся только в вашем локальном `config.json`.

Поддерживаются и Anthropic-стиль, и OpenAI-стиль API, а также локальные серверы (Ollama, LM Studio, vLLM, llama.cpp). Полное руководство: [docs/providers.md](docs/providers.md).

## Сборка ORCA

```bash
npm run fetch-bins   # ffmpeg, yt-dlp, данные OCR (не хранятся в git)
npm run dist:win     # release/ORCA-Agent-<version>-win-x64.zip
npm run dist:mac     # release/ORCA-Agent-<version>-mac-{x64,arm64}.{zip,dmg}   (на macOS)
npm run dist:linux   # release/ORCA-Agent-<version>-linux-x64.{AppImage,tar.gz,deb}
```

Релизы собираются GitHub Actions на каждый тег `v*`. Сопровождающим: см. [docs/setup.md#maintainers](docs/setup.md#maintainers) о процессе релизов и ротации ключей.
